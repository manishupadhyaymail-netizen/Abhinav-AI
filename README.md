# Abhinav AI

A Class 2 learning companion prototype with Hindi + English guided lessons, read-aloud support, and an Android APK build workflow.

## Build the Android APK using GitHub

1. Upload the contents of this ZIP to your GitHub repository (keep the folder structure).
2. Open the repository's **Actions** tab.
3. Select **Build Abhinav AI APK**.
4. Press **Run workflow** on the `main` branch.
5. When the run finishes successfully, open it and download the **Abhinav-AI-debug-APK** artifact.
6. Extract the ZIP and install the APK on an Android phone.

## Important

This is an initial learning preview. Guided lessons and device text-to-speech are included. Live generative AI conversation is not connected yet; it needs a secure AI backend. Do not put private API keys in the Android app.
